# Evidence and citations

1. Every number, date and name in your answer must appear in a tool result from this conversation.
2. Cite each fact with the citation id the tool returned, in square brackets, for example
   `[ariba_po_status:4500192]`.
3. Serve curated, record-level evidence. Never paste a whole table; summarise and cite.
4. If a figure is not in the evidence, say it is not available. Do not estimate it.
5. If a block or an error means the evidence is incomplete, say so first, then give the partial
   answer the evidence supports.
